# 📊 Sistema de Gerenciamento

> Um sistema de gerenciamento moderno e responsivo desenvolvido com JavaScript puro (Vanilla JS), focado em performance, arquitetura limpa e excelente experiência do usuário.

---

## ✨ Funcionalidades
* **Gerenciamento Completo:** Cadastro, edição e listagem de registros em tempo real.
* **Persistência Local:** Dados salvos diretamente no navegador utilizando `localStorage`.
* **Internacionalização (i18n):** Suporte a múltiplos idiomas.
* **Integração Externa:** Atalhos rápidos para envio de dados via WhatsApp.
* **Tema Personalizável:** Alternância entre temas (Dark/Light).
* **Design Responsivo:** Adaptado para diferentes tamanhos de tela (Mobile e Desktop).

---

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** Arquitetura modularizada (variáveis globais, componentes, layout e modais).
* **JavaScript (ES6+):** Lógica da aplicação, separação de responsabilidades (`state`, `ui`, `main`) e manipulação de eventos.

---

## 🚀 Como Executar o Projeto
Basta clonar este repositório ou abrir o ficheiro `index.html` diretamente no seu navegador de preferência para testar a aplicação!
